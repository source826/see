# 导盲视觉（guidao-vision）

真实街景视频 / 摄像头 → YOLOv8n 检测 → 跟踪 ID → 面积与中心逼近判定 → 分级中文语音提示。

> 实验性辅助提醒，不能替代盲杖等其他导盲方式。

- 实时页：[index.html](index.html)（`?video=` 载入本地视频，`?t=` 指定起始秒，`?webgpu=1` 尝试 WebGPU）
- 地图导航（实验）：实时页侧栏，OSM 瓦片 + GPS + 目的地方向/距离；只做直线提示，不是转弯级路线
- 量化评测台：[eval.html](eval.html)
- YOLO 独立演示页：[yolo-demo/index.html](yolo-demo/index.html)
- 演示视频：[GitHub Releases v0.1](https://github.com/source826/see/releases/tag/v0.1)（视频不放入 commit；B站链接待补）

## 快速开始

```bash
node tools/serve.mjs 8080
```

- 实时页：`http://localhost:8080/index.html`
- 评测台：`http://localhost:8080/eval.html`
- 测试：`npm test`；本机没有 npm 时用 `node --test tests`
- 实时对齐评测（Edge，需先启动本地服务）：
  ```bash
  node tools/live_eval.mjs --videoUrl=assets/videos/tune/nanjing_00.mp4 --port=9400 --out=tmp/live.json
  node tools/live_eval_report.mjs tmp/live.json gt/nanjing_00_sample.json
  ```
  第一个脚本让实时页按真实速度播放并记录实际处理帧（frame/dt/检测/轨迹/报警）；第二个脚本把 GT 按 track id 插值到这些帧，用同一套事件评测计算召回、提前量和误报。

### 相机高度、俯角与估距

实时页可输入相机离地高度和俯角（默认 1.5m / 10°），系统按地面几何估算距离：

```
y' = (y_ground - H/2) / f
d = H * (1 - y' * tanθ) / (y' + tanθ)
f = W / (2 * tan(HFOV / 2))
```

- `H` 为相机离地高度，`θ` 为相机光轴向下俯角（0=水平）。
- 高度/俯角改变后实时生效；可用 `?cam=1.5&pitch=10` 校准。
- 轨迹预判：用最近 6 帧框中心做线性回归估计速度，外推 1.4s（可调 0.8–2.5s），只做短时外推；路径末端标注预判秒数，供反应时间参考。
- 用户播报只说“很近 / 近 / 有点远”，具体米数只保留在 JSON 和叠加层调试信息里。
- 框底在地平线以上或几何值异常时，自动回退到框高估距。
- 评测台与离线演示默认仍用框高估距，以保持历史指标可比。

### 台阶与坡道提醒

- **台阶（暂缓播报）**：街景中的栏杆、树影、花坛会产生等间距水平边缘，实测 `nanjing_02` 会把平地判成台阶。误报会让人在车道上停下摸索，比漏报更危险；当前版本不播报台阶，检测代码与单测保留，等有正样本和更强验证后再开。
  - 既有检测：下方中央 ROI 等间距水平边缘，连续 2 帧确认；`stairs_pov.mp4` 可触发，但街景误报未解决。
- **上坡/下坡**：使用手机姿态传感器（`DeviceOrientationEvent`）的俯仰变化。
  - 点击实时页的“校准姿态/坡道”，在平地上按平常握持角度站约 2 秒完成校准。
  - `beta` 增大按上坡、减小按下坡；变化 3.5°–7° 时保守说“前方有坡道，请小心”。
  - 语音：`前方上坡，请小心` / `前方下坡，请小心`。
- 地形语音不会和“冲过来”叠放：目标语音结束后至少 2 秒才播地形；地形提醒使用独立冷却。
- 桌面浏览器通常没有姿态传感器，坡道提醒会提示“没有收到姿态数据”；台阶检测不依赖传感器。

### 红绿灯

- YOLO 检出红绿灯框后，对框内高饱和红/黄/绿像素投票；连续 3 帧同色才确认。
- 红灯、黄灯提示等待；绿灯只说“请确认行人信号”，不直接说可以通行。
- 远距离小灯在 320 分析宽度下可能检不到；需要更高分辨率或专用裁剪。

### 评测口径与当前结果（2026-11-23）

**口径收严**
- 报警以实时页**实际播出的语音**为准（`__guidaoAlerts`），不再把每帧风险等级当报警。旧口径会把被冷却压掉的重复提示算成误报，也会把没播出的等级算成召回。
- **主指标是按目标召回**：每个 GT 事件目标是否在进入通道前收到映射到它的语音报警。群体召回（1.5 s 内一起进通道的目标算一组）只作辅助；“目标覆盖”只用于诊断是否最终提醒到，不能替代提前召回。
- 误报只在 GT 有背景标注、且覆盖片长 ≥60% 时给“次/分”；半自动样例 GT 只给原始报警，不把未标注的真实行人当误报。

**诊断（2026-11-23）**

- 8 个事件目标在系统里的 `approachingFrames` **全部为 0**：面积增长法没有判出任何一个。检出匹配并不差（narrow 5/5、8/12；hutong 37/46、31/36；tunnel 7/9、19/20、4/4），问题在“逼近判定”，不是完全没检出。
- 首次匹配经常晚于进通道：hutong 173 vs 164、240 vs 223；narrow 360 vs 331。这是远距离小目标跟踪延迟，报警规则再早也早不过第一条轨迹。
- tunnel 三个事件目标 `strictFrames=0`，从未进严格通道；按当前产品规则本来就静默。GT 事件用的是宽通道，这是**评测定义与产品静默规则冲突**，不全是算法漏报。

### 降误报策略（调参集调参，新素材只验一次）

1. **只报主目标**：同一帧按“等级 → 距离”选一个，其余 `level` 归零；播报层只处理 `primaryId`，避免多人同时逼近时抢话。
2. **同一目标冷却**：同一 `kind+trackId` 最小间隔 6 s；同类冷却 rush/uncertain 2.5 s、static 8 s；“刚喊过冲过来”的降级保护只作用于同一目标，不再压住别的目标。
3. **必须进通道**：风险层 level 2 可用宽走廊，但播报层只对**严格走廊**内的 level 2 开口；横穿车辆用“预测脚点 2 s 内进严格走廊”提前报，不等已经进通道。
4. **场景分开定义**：
   - 街景：宽走廊 + 预测不离开 + 立姿框；静止障碍 8 m；允许“前方有情况”。
   - 人群（自动判定：中央 80% 内 ≥4 个近处行人）：只认严格走廊、距离 ≤5 m、框高持续膨胀（>3%/s）且 `hits≥8`；不报宽走廊 level 2，不报泛化的“有情况”；静止障碍只在贴脸时报。人群专用文案“有人靠近，请留意”。
   - 横穿：只对车辆（含自行车/摩托车），且车辆必须已进入宽通道；要求侧向速度 ≥6% 画面宽/秒、侧向分量压过纵向，预测 2 s 内进严格走廊、距离 ≤18 m；进入横穿场景后不再播静止障碍/“有情况”。

**本轮规则改动的召回 / 误报代价**

| 规则改动 | 按目标召回变化 | 误报变化 | 说明 |
|---|---|---|---|
| 同类冷却 12 s→2.5 s + 降级保护只作用于同一目标（含播报层只在严格通道跟随 level 2） | nj00 0→0.25；nj02 0→0.50 | nj00 1.44→0；nj02 4.32→0 次/分 | 本轮最大收益：召回和误报同时改善；三项同批发布，未完全拆分 |
| 横穿规则：只给车辆、且必须已进宽通道（同时纳入自行车） | nj00 0.25→0.25；nj02 0.50→0.50 | nj00 0→1.44；nj02 0→0 次/分 | 召回不变；nj02 提前量 1.37→3.10 s。自行车纳入后 nj00 多出 1 段横穿提醒，未换来召回提升 |
| `primaryOnly` 开 / 关 | 0.25 → 0.25（nj00） | 2.88 → 2.88 次/分 | 只少抢话（16 / 15 条），不单独降误报 |
| 人群 looming 规则（严格通道 + 框高膨胀） | 覆盖率 0/2 → 2/2 | 0 → 0 | 修复“人群场景完全不播报” |

### 静默场景（使用者必须知道）

- **横穿场景只播车辆**：行人横穿、行人横向走过通道、骑车人未满足“已进宽通道 + 侧向速度”条件时，不会播报。横穿场景也不播“静止障碍”和泛化的“前方有情况”。
- **人群场景只播“通道里持续膨胀的人”**：站着不动、横向走开、或不在严格通道内的人不会播；人群里也不播泛化的“有情况”。
- **街景只对严格通道内的 level 2 开口**：严格通道外的侧边行人/车辆不播。
- **环境层继续静默**：台阶、斑马线偏离、地面小障碍当前版本不播，只有红/黄/绿灯和坡道保留。
- 这不是“所有危险都会报”的系统；它优先保证不因误报把人引到车道上。

### 斑马线（暂缓播报）

- 检测下方中央的多条平行白色横条，用直线拟合左右边界；缺一段时按拟合直线补齐，不要求白条连续。
- 方向文案已实现：左偏说“已向左偏离斑马线，请向右靠”，右偏说“已向右偏离斑马线，请向左靠”；在补齐范围内不报，走到斑马线尽头（白条消失）也不报。
- 合成测试覆盖连续、缺块、左偏、右偏、无斑马线，但真实街景里的车道线/白色标线会被误判成斑马线；清晰斑马线正样本视频仍待补（**正样本待补**）。
- 当前版本不播报斑马线偏离，避免在普通街道上把人引向错误方向；检测、方向文案和单测保留。

### 地面小障碍（暂缓）

- 当前版本不接入语音和横幅提醒；检测代码与单测保留，后续再评估。
- 现有 YOLO 类别只能覆盖香蕉、瓶子、杯子等少数 COCO 类；**石墩子、西瓜皮没有对应类别**，暂不作为交付功能。
